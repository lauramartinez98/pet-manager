# Pet Manager - Design System & UI Guidelines

## 1. Paleta de Colores
- **Butter Yellow:** Usar para fondos generales de la aplicación, fondos de tarjetas grandes y áreas que necesiten transmitir calidez.
- **Soft Blue:** Usar para elementos secundarios, fondos del Navbar lateral, insignias (badges) de información o estados inactivos.
- **Brown:** Usar para tipografía principal, títulos, iconos y botones de acción primaria (ej. "Añadir mascota", "Guardar").

## 2. Estilo Visual
- Todas las imágenes de mascotas deben ser circulares o con bordes muy redondeados (`border-radius: 50%` o `rounded-full`).
- Las tarjetas (cards) de información (gastos, paseos, citas) deben tener bordes suavemente redondeados y una sombra ligera para separarse del fondo.
- La estética general debe ser amigable, limpia y orientada a los animales (mascotas).

## 3. Layout Principal
- Navbar fijo en el lado izquierdo (100vh de alto).
- El área derecha ocupará el resto del ancho y contendrá el panel de gestión dinámico.
