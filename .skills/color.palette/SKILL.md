# Skill: Color Palette & UI Design
name: color-palette
description: Aplica estrictamente la paleta de colores oficial (Butter Yellow, Soft Blue, Brown) y directrices visuales en todos los componentes de React.

## Instrucciones para el Agente:
Cuando escribas o modifiques código de interfaz (React / Tailwind / CSS):
1. **Butter Yellow (#FAF0CA o similar suave):** Usar exclusivamente para fondos principales, tarjetas grandes de contenido y áreas que requieran calidez.
2. **Soft Blue (#A9BCD0 o similar):** Usar para el Navbar lateral, elementos secundarios, y estados inactivos o badges informativos.
3. **Brown (#582F0E o similar):** Usar para la tipografía principal, títulos destacados, iconos y botones de acción primaria (ej. "+ Nuevo miembro").
4. **Bordes y Sombras:** Todas las imágenes de mascotas deben ser circulares (`rounded-full`) y las tarjetas deben tener sombras suaves y bordes redondeados limpios.
